# Parlant 核心模块源码地图

按"上下文工程组件 → 源码位置 → 关键类/函数 → 职责"梳理，方便对照源码精读。

---

## 一、入口与编排

| 模块 | 文件 | 关键类/函数 | 职责 |
|---|---|---|---|
| 服务启动 | `bin/`、`core/application.py` | `Application` | 组装容器、启动 API 服务 |
| API 会话 | `api/sessions.py` | `create_event()`、`_add_customer_message()`、`create_session()` | 事件创建入口、鉴权、输入审核、`trigger_processing` |
| 会话服务 | `core/sessions.py` | `SessionStore`、`process()`、`create_event()` | 事件持久化、触发引擎、offset/trace_id 管理 |
| **引擎** | `core/engines/alpha/engine.py` | `AlphaEngine.process()`、`_do_process()`、`utter()` | 全链路主编排（准备循环+生成） |
| 引擎上下文 | `core/engines/alpha/engine_context.py` | `EngineContext`、`ResponseState` | 单次响应的累积状态载体 |
| 计划编排 | `core/engines/alpha/planners.py` | `Planner`、`Plan` | 自定义编排钩子（create_plan/on_tools_inferred…） |
| 钩子 | `core/engines/alpha/hooks.py` | `Hooks` | 生命周期回调（on_preparing/on_generating_messages…） |

## 二、上下文工程核心组件

### 1. Guidelines（指南）
| 模块 | 文件 | 关键类/函数 |
|---|---|---|
| 数据模型/存储 | `core/guidelines.py` | `Guideline`、`condition/action/criticality` |
| 匹配器 | `core/engines/alpha/guideline_matching/guideline_matcher.py` | `GuidelineMatcher.match_guidelines()`、`GuidelineMatchingBatch` |
| 通用策略 | `.../generic/generic_guideline_matching_strategy.py` | `GenericGuidelineMatchingStrategy` |
| 评估 batch | `.../generic/*_batch.py` | actionable / observational / low_criticality / disambiguation / response_analysis |
| 旅程相关匹配 | `.../generic/journey/*` | node_selection / next_step_selection / backtrack_check |

### 2. Journeys（旅程）
| 模块 | 文件 | 关键类/函数 |
|---|---|---|
| 数据模型/状态机 | `core/journeys.py` | `Journey`、`State`、`Transition`、入口/转移判定 |
| 旅程→指南投影 | `core/journey_guideline_projection.py` | 把旅程节点/转移投影为可匹配指南 |

### 3. Tools（工具）
| 模块 | 文件 | 关键类/函数 |
|---|---|---|
| 数据模型 | `core/tools.py` | `Tool`、`ToolParameter` |
| 工具调用编排 | `core/engines/alpha/tool_event_generator.py` | `infer_tool_calls()`、`execute_tool_calls()` |
| 单次工具 batch | `core/engines/alpha/tool_calling/single_tool_batch.py` | 单工具 LLM 调用 |
| 重叠工具 batch | `core/engines/alpha/tool_calling/overlapping_tools_batch.py` | 多工具并行调用 |
| 插件服务 | `core/services/tools/plugins.py` | `@p.tool` 装饰器、参数 schema 生成 |
| OpenAPI/MCP | `core/services/tools/openapi.py`、`mcp_service.py` | 外部工具接入 |

### 4. Retrievers（检索器）
| 模块 | 文件 | 关键类/函数 |
|---|---|---|
| 检索器模型 | `core/engines/alpha/` 内以工具形式接入 | `RetrieverContext`（server/container/logger/trace_id/interaction/agent/customer/variables） |
| 向量库适配 | `adapters/vector_db/` | `qdrant.py` 等，可插拔 |
| 检索结果 | — | 仅当前响应生效，不跨轮持久 |

### 5. Relationships（关系）
| 模块 | 文件 | 关键类/函数 |

### 6. Variables（变量）

| 内置计数工具 | 内置 tool `journey_node_counter` | 旅程节点访问计数 |

### 7. Glossary（术语表）
| 模块 | 文件 | 关键类/函数 |

### 8. Canned Responses（预设话术）

## 六、读源码的建议顺序

1. `api/sessions.py` 的 `create_event` → 看清请求如何进来。
2. `core/engines/alpha/engine.py` 的 `process`/`_do_process` → 主编排（本文核心）。
3. `_load_matched_guidelines_and_journeys` 9 步 → 指南/旅程如何被选中。
4. `tool_event_generator.py` → 工具与检索器如何执行并驱动再迭代。
5. `message_generator.py` 的 `_build_prompt` → 上下文如何拼成提示词。
6. `core/emissions.py` + `core/tracer.py` → 可追溯性如何落地。
