# 安装（Installation）

![Parlant Logo](https://parlant.io/logo/logo-full.svg)

**Parlant** 是一个开源的**对话型管控框架（conversational harness）**，用于构建可扩展且可靠的面客（customer-facing）智能体。

它提供一系列为对话而优化的原语（primitives），让你对智能体「看到什么、说什么、何时、为何」获得干净、结构化且可维护的控制——从而构建出交互可预测、一致、可追溯且可安全部署的面客智能体。

它在实践中的体现如下：

- **[观察（Observations）](https://parlant.io/docs/concepts/customization/guidelines#the-core-primitive-observations)**：
  核心原语。Observations 监视对话，并在某个条件（condition）满足时触发，让你能挂钩对话状态，并精确控制哪些内容——指南、工具、检索信息、旅程等等——在何时进入智能体的上下文。这即使在有数百个上下文元素的情况下，也能让智能体保持专注与一致。

- **[指南（Guidelines）](https://parlant.io/docs/concepts/customization/guidelines#guidelines-observations-with-actions)**：
  附加了动作（action）的 Observations。定义细粒度的行为规则，告诉智能体在检测到特定条件时该做什么。

- **[工具使用（Tool Use）](https://parlant.io/docs/concepts/customization/tools)**：
  将外部 API 与后端服务挂接到 Observations 上。工具只在其关联的 Observation 触发时才进入智能体上下文，从而消除误报（false-positive）的工具调用。

- **[旅程（Journeys）](https://parlant.io/docs/concepts/customization/journeys)**：
  定义多轮的标准操作流程（Standard Operating Procedures，SOP）。它们不是僵化的脚本：你的智能体会适应用户的交互模式，同时始终把握全局。

- **[预设话术（Canned Responses）](https://parlant.io/docs/concepts/customization/canned-responses)**：
  在高风险或敏感的场合，通过有选择地跳过输出生成、使用预批准的回复模板来消除幻觉（hallucinations）。

- **[领域理解（Domain Understanding）](https://parlant.io/docs/concepts/customization/glossary)**：
  教会你的智能体领域专属术语，并将其锚定在你的业务词汇表上。每一条 Observation、指南与工具都会考虑术语表定义。

- **[可追溯性（Traceability）](https://parlant.io/docs/advanced/explainability)**：
  每一轮都能检查究竟是哪些 Observations 与指南被触发、为何被触发，以及它们产出了什么。

### 它是如何运作的（How It Works）

当你的智能体收到一条消息时，Parlant 会动态组装正确的上下文，并生成一次受控的回复：

只有与当前对话轮次相关的 Observations、指南和工具会被加载进上下文——即使在有数百条行为规则的情况下，也能让模型保持专注、一致与可追溯。

## 安装（Installation）
Parlant 在 [GitHub](https://github.com/emcie-co/parlant) 和 [PyPI](https://pypi.org/project/parlant/) 上均可获得，并支持多种平台（Windows、Mac 和 Linux）。

请注意，Parlant 需要 [Python 3.10](https://www.python.org/downloads/release/python-3105/) 及以上版本才能正常运行。

```bash
pip install parlant
```

如果你有探索精神，想体验新功能，也可以直接从 GitHub 安装最新的开发版本。

```bash
pip install git+https://github.com/emcie-co/parlant@develop
```

## 创建你的第一个智能体（Creating Your First Agent）

安装完成后，你可以使用以下代码启动一个初始的示例智能体。之后你可以逐步丰富它的行为。

```python
# main.py

import asyncio
import parlant.sdk as p

async def main():
  async with p.Server() as server:
    agent = await server.create_agent(
        name="Otto Carmen",
        description="You work at a car dealership",
    )

asyncio.run(main())
```

你会发现 Parlant 遵循使用 `async` 和 `await` 的异步编程范式。这是 Python 的一项强大特性，使你能编写同时处理多个任务的代码，从而让智能体在生产环境中处理更多并发请求。

如果你对异步编程还不熟悉，可以参阅 [Python 官方文档](https://docs.python.org/3/library/asyncio.html) 快速入门。

#### NLP 服务配置（NLP Service Configuration）

Parlant 官方推荐使用的 NLP 服务是 [Emcie](https://emcie.co/)，因为其模型针对 Parlant 的引擎（指南匹配、消息生成等）做了专门优化，与通用模型提供商相比，能带来更低的成本和更少的延迟。[了解更多关于 Emcie 推理平台的信息](https://docs.emcie.co/docs/getting-started)。

要开始使用，请设置你的 API 密钥并运行程序：

```bash
export EMCIE_API_KEY="<YOUR_API_KEY>"
```

```bash
python main.py  # 运行服务器
```

#### 使用其他 LLM 提供商（Using Other LLM Providers）

Parlant 通过 `p.NLPServices` 类支持多种 LLM 提供商。

要使用备选提供商，请在创建服务器时指定它：

```python
async with p.Server(nlp_service=p.NLPServices.openai) as server:
  ...
```

**支持的提供商**

| 提供商 | 额外包 | 环境变量 |
| --- | --- | --- |
| Emcie（默认） | 内置 | `EMCIE_API_KEY` |
| OpenAI | 内置 | `OPENAI_API_KEY` |
| Anthropic | `parlant[anthropic]` | `ANTHROPIC_API_KEY` |
| Google Gemini | `parlant[gemini]` | `GOOGLE_API_KEY` |
| Google Vertex AI | `parlant[vertex]` | Google Cloud 凭据 |
| AWS Bedrock | `parlant[aws]` | AWS 凭据 |
| Azure OpenAI | `parlant[azure]` | `AZURE_OPENAI_API_KEY` |
| Cerebras | `parlant[cerebras]` | `CEREBRAS_API_KEY` |
| Together AI | `parlant[together]` | `TOGETHER_API_KEY` |
| DeepSeek | `parlant[deepseek]` | `DEEPSEEK_API_KEY` |
| Ollama | `parlant[ollama]` | —（本地） |
| LiteLLM | `parlant[litellm]` | 取决于底层提供商 |

要获取最新、最完整的受支持提供商列表，请参阅 [`pyproject.toml`](https://github.com/emcie-co/parlant/blob/main/pyproject.toml) 与 `p.NLPServices` 工厂类。

对于需要额外包的提供商，请务必使用 pip 安装它：

```bash
pip install "parlant[anthropic]"
```

你也可以通过实现 `p.NLPService` 接口来添加自己的提供商，具体方法可在 [自定义 NLP 模型（Custom NLP Models）](https://parlant.io/docs/advanced/custom-llms) 一节中了解。

## 创建你的第一条指南（Creating Your First Guideline）

在 Parlant 中，你通过创建**观察（observations）**和**指南（guidelines）**来控制智能体。一条 observation 会监视对话，并在某个条件满足时触发；一条 guideline 则是附加了动作的 observation——它告诉智能体在检测到该条件时*做*什么。

Parlant 每一轮只加载相关的 observations 与 guidelines，因此你可以按需添加任意数量，而无需担心上下文过载或指令遵从能力下降。

```python
# main.py

import asyncio
import parlant.sdk as p

async def main():
  async with p.Server() as server:
    agent = await server.create_agent(
        name="Otto Carmen",
        description="You work at a car dealership",
    )

    ##############################
    ##    Add the following:    ##
    ##############################
    await agent.create_guideline(
        # This observation condition detects when the guideline should fire
        condition="the customer greets you",
        # This action tells the agent what to do
        action="offer a refreshing drink",
    )

asyncio.run(main())
```

现在重新运行该程序：
```bash
python main.py
```

刷新 [http://localhost:8800](http://localhost:8800)，启动一个新的会话，并与智能体打招呼。你应该会被招待一杯饮品！

## 使用官方 React 组件（Using the Official React Widget）

如果你的前端项目是用 React 构建的，最快、最简单的起步方式是使用官方的 Parlant React 组件与服务器集成。

以下是一个基础代码示例，帮助你快速开始：

```jsx
import React from 'react';
import ParlantChatbox from 'parlant-chat-react';

function App() {
  return (
    <div>
      <h1>My Application</h1>
      <ParlantChatbox
        server="PARLANT_SERVER_URL"
        agentId="AGENT_ID"
      />
    </div>
  );
}

export default App;
```

更多文档与定制方式，请参见 **GitHub 仓库：** https://github.com/emcie-co/parlant-chat-react。

```bash
npm install parlant-chat-react
```

## 安装客户端 SDK（Installing Client SDK(s)）

要创建一个与 Parlant 服务器交互的自定义前端应用，我们推荐安装我们的原生客户端 SDK。我们目前支持 Python 和 TypeScript（同样适用于 JavaScript）。

#### Python
```bash
pip install parlant-client
```

#### TypeScript/JavaScript
```bash
npm install parlant-client
```

你可以在这里查阅我们关于集成自定义前端的教程：[自定义前端集成（Custom Frontend Integration）](https://parlant.io/docs/production/custom-frontend)。
