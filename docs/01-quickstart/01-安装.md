# 安装（Installation）

![Parlant Logo](https://parlant.io/logo/logo-full.svg)

**Parlant** 是一个开源的**面向 LLM 智能体的智能行为建模引擎（Agentic Behavior Modeling Engine）**，旨在帮助开发者快速构建面向客户、对齐业务目标的对话式智能体（Agent），同时兼顾可控性、清晰度和信心。

它为你提供了构建面向客户的智能体所需的一切结构，使其行为完全符合你的业务要求：

- **[旅程（Journeys）](https://parlant.io/docs/concepts/customization/journeys)**：
  定义清晰的客户旅程，以及你的智能体在每一步应如何响应。

- **[行为指南（Behavioral Guidelines）](https://parlant.io/docs/concepts/customization/guidelines)**：
  轻松雕琢智能体行为；Parlant 会根据情境匹配相关要素。

- **[工具使用（Tool Use）](https://parlant.io/docs/concepts/customization/tools)**：
  将外部 API、数据抓取器或后端服务挂接到特定的交互事件上。

- **[领域适配（Domain Adaptation）](https://parlant.io/docs/concepts/customization/glossary)**：
  教会你的智能体领域专属术语，并生成个性化回复。

- **[预设话术（Canned Responses）](https://parlant.io/docs/concepts/customization/canned-responses)**：
  使用回复模板消除幻觉（hallucinations），并保证风格一致性。

- **[可解释性（Explainability）](https://parlant.io/docs/advanced/explainability)**：
  理解每条指南（Guideline）为何在何时被匹配并被遵循。

## 安装（Installation）
Parlant 在 [GitHub](https://github.com/emcie-co/parlant) 和 [PyPI](https://pypi.org/project/parlant/) 上均可获得，并支持多种平台（Windows、Mac 和 Linux）。

请注意，Parlant 需要 [Python 3.10](https://www.python.org/downloads/release/python-3105/) 及以上版本才能正常运行。

```bash
pip install parlant
```

如果你有探索精神，想体验新功能，也可以直接从 GitHub 安装最新的开发版本。

```bash
pip install git+https://github.com/emcie-co/parlant@develop
```

## 创建你的第一个智能体（Creating Your First Agent）

安装完成后，你可以使用以下代码启动一个初始的示例智能体。之后你可以逐步丰富它的行为。

```python
# main.py

import asyncio
import parlant.sdk as p

async def main():
  async with p.Server() as server:
    agent = await server.create_agent(
        name="Otto Carmen",
        description="You work at a car dealership",
    )

asyncio.run(main())
```

你会发现 Parlant 遵循使用 `async` 和 `await` 的异步编程范式。这是 Python 的一项强大特性，使你能编写同时处理多个任务的代码，从而让智能体在生产环境中处理更多并发请求。

如果你对异步编程还不熟悉，可以参阅 [Python 官方文档](https://docs.python.org/3/library/asyncio.html) 快速入门。

Parlant 默认使用 OpenAI 作为 NLP 提供商，因此你需要确保在环境中设置了 `OPENAI_API_KEY`。

然后，运行该程序！
```bash
export OPENAI_API_KEY="<YOUR_API_KEY>"
python main.py
```

Parlant 默认支持多种 LLM 提供商，可通过 `p.NLPServices` 类访问。你也可以通过实现 `p.NLPService` 接口来添加自己的提供商，具体方法可在 [自定义 NLP 模型（Custom NLP Models）](https://parlant.io/docs/advanced/custom-llms) 一节中了解。

要使用内置提供商之一，你可以在创建服务器时指定它。例如：

```python
async with p.Server(nlp_service=p.NLPServices.cerebras) as server:
  ...
```

请注意，某些提供商可能需要安装额外的 "extra" 包。例如，要使用 Cerebras NLP 服务：

```bash
pip install parlant[cerebras]
```

话虽如此，据观察，Parlant 与 [OpenAI](https://openai.com) 和 [Anthropic](https://www.anthropic.com) 模型配合效果最佳，因为这些模型在生成高质量、具备有效 JSON 模式（schema）的补全方面高度一致——因此如果你刚起步，我们推荐使用其中之一。

要测试你的安装，请前往 [http://localhost:8800](http://localhost:8800) 并启动一个新的会话（Session）与智能体对话。

## 创建你的第一条指南（Creating Your First Guideline）

指南（Guideline）是 Parlant 行为模型的核心。它们允许你定义智能体应如何响应特定的用户输入或条件（Condition）。Parlant 会巧妙地为你管理指南上下文，因此你可以添加任意数量的指南，而无需担心上下文过载或其他规模问题。

```python
# main.py

import asyncio
import parlant.sdk as p

async def main():
  async with p.Server() as server:
    agent = await server.create_agent(
        name="Otto Carmen",
        description="You work at a car dealership",
    )

    ##############################
    ##    Add the following:    ##
    ##############################
    await agent.create_guideline(
        # This is when the guideline will be triggered
        condition="the customer greets you",
        # This is what the guideline instructs the agent to do
        action="offer a refreshing drink",
    )

asyncio.run(main())
```

现在重新运行该程序：
```bash
python main.py
```

刷新 [http://localhost:8800](http://localhost:8800)，启动一个新的会话，并与智能体打招呼。你应该会被招待一杯饮品！

## 使用官方 React 组件（Using the Official React Widget）

如果你的前端项目是用 React 构建的，最快、最简单的起步方式是使用官方的 Parlant React 组件与服务器集成。

以下是一个基础代码示例，帮助你快速开始：

```jsx
import React from 'react';
import ParlantChatbox from 'parlant-chat-react';

function App() {
  return (
    <div>
      <h1>My Application</h1>
      <ParlantChatbox
        server="PARLANT_SERVER_URL"
        agentId="AGENT_ID"
      />
    </div>
  );
}

export default App;
```

更多文档与定制方式，请参见 **GitHub 仓库：** https://github.com/emcie-co/parlant-chat-react。

```bash
npm install parlant-chat-react
```

## 安装客户端 SDK（Installing Client SDK(s)）

要创建一个与 Parlant 服务器交互的自定义前端应用，我们推荐安装我们的原生客户端 SDK。我们目前支持 Python 和 TypeScript（同样适用于 JavaScript）。

#### Python
```bash
pip install parlant-client
```

#### TypeScript/JavaScript
```bash
npm install parlant-client
```

你可以在这里查阅我们关于集成自定义前端的教程：[自定义前端集成（Custom Frontend Integration）](https://parlant.io/docs/production/custom-frontend)。

至于其他语言——它们即将推出！与此同时，你可以直接使用 [REST API](https://parlant.io/docs/api/create-agent)。
