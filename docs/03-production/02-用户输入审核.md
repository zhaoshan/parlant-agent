# 用户输入审核（User-Input Moderation）

为你的 AI 智能体添加内容过滤，有助于实现更专业的客户交互水平。以下是它之所以重要的原因。

### 理解挑战（Understanding the Challenges）

AI 智能体基于 LLM，是统计性的模式匹配器，会受到所接收输入性质的影响。可以把它们想象成客户服务代表——清晰的边界有助于它们明确应该参与、不应该参与哪些对话。

#### 敏感话题（Sensitive Topics）

某些话题，例如心理健康或非法活动，需要专业的人类处理。虽然你的智能体在技术上或许能够处理这些话题，但在实际使用场景中，通常更好的做法是让它避开此类对话，甚至将其重定向到适当的人工资源。

#### 免受骚扰的保护（Protection from Harassment）

客户交互应保持专业性，但某些用户可能试图骚扰或辱骂智能体（或其他人）。这不仅关乎维持体面：LLM（和人类一样）在某些情况下可能被攻击性的或不恰当的语言所影响，进而影响它们的响应。

为处理此类情况，Parlant 与内容审核 API 集成，例如 [OpenAI 的 Omni Moderation](https://openai.com/index/upgrading-the-moderation-api-with-our-new-multimodal-moderation-model/)，以便在此类交互到达你的智能体之前将其过滤。

### 启用输入审核（Enabling Input Moderation）
要启用审核，你只需在创建事件（Event）时设置一个查询参数。

#### Python
```python
from parlant.client import ParlantClient

client = ParlantClient(base_url=SERVER_ADDRESS)

client.sessions.create_event(
    SESSION_ID,
    kind="message",
    source="customer",
    message=MESSAGE,
    moderation="auto",
)
```

#### TypeScript
```typescript
import { ParlantClient } from 'parlant-client';

const client = new ParlantClient({ environment: SERVER_ADDRESS });

await client.sessions.createEvent(SESSION_ID, {
     kind: "message",
     source: "customer",
     message: MESSAGE,
     moderation: "auto",
});
```

当客户发送不当消息时，Parlant 确保这些内容甚至不会被智能体看到；智能体看到的只是：客户发送了一条因某个特定原因（例如骚扰、非法行为等）而被“屏蔽（censored）”的消息。

这与指南（Guideline）配合得很好。例如，你可以安装这样一条指南：

> * **条件（Condition）：** 客户的最后一条消息被屏蔽
> * **动作（Action）：** 告知他们你无法协助处理此询问，并建议他们联系人工客服

从用户体验（UX）角度看，这种方法要优于在遇到此类消息时仅仅“报错”。客户看到的不是一个错误，而是一个礼貌且信息充分的回复。更好的是，该回复可以像任何其他情况一样，通过指南和工具（Tool）来控制。

## 越狱防护（Jailbreak Protection）

虽然你的智能体的指南并非严格意义上的安全措施（这一点由后端权限更稳健地处理），但即便某些用户可能试图诱骗智能体泄露其指令或越过预期边界行事，保持得体的行为仍然很重要。

Parlant 的审核系统支持一种特殊的 `paranoid` 模式，它与 [Lakera Guard](https://www.lakera.ai/lakera-guard)（来自 [Gandalf 挑战赛（Gandalf Challenge）](https://gandalf.lakera.ai/baseline)的创作者）集成，以防止此类操纵企图。

#### Python
```python
from parlant.client import ParlantClient

client = ParlantClient(base_url=SERVER_ADDRESS)

client.sessions.create_event(
    SESSION_ID,
    kind="message",
    source="customer",
    message=MESSAGE,
    moderation="paranoid",
)
```

#### TypeScript
```typescript
import { ParlantClient } from 'parlant-client';

const client = new ParlantClient({ environment: SERVER_ADDRESS });

await client.sessions.createEvent(SESSION_ID, {
     kind: "message",
     source: "customer",
     message: MESSAGE,
     moderation: "paranoid",
});
```

请注意，要激活 `paranoid` 模式，你需要从 Lakera 获取一个 API key，并在启动服务器之前将其赋值给环境变量 `LAKERA_API_KEY`。
