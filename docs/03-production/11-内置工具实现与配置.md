# 内置工具实现与配置（自研）

> 2026-09-23 核实：`agent-definition.json` tools[] 里 `source="builtin"` 的
> `journey_node_counter` / `variable_update` / `tavily_search` **是我们在
> `parlant-agent-runtime/app/services/builtin_tools.py` 自研实现**，Parlant 框架并不提供。
> 框架只提供 `@p.tool` 装饰器 + ToolEntry/ToolService 机制；工具函数体与语义由我们定义。

---

## 0. 生效机制（为什么"配置了就能被调用"）

```
agent-definition.json tools[] 声明工具元数据（id/name/description/input_schema, source="builtin"）
  → loader resolve_tool("工具名") 返回 builtin_tools.py 里 @p.tool 的 ToolEntry（即 ToolRef）
  → 挂到 tool 节点的 node.tools（journey tool_state）或指南的 tools
  → SDK 收集 ToolEntry 注册进集成 "built-in" 工具服务（PluginServer.tools 字典，key=工具名）
  → 引擎进入 tool 节点/命中指南 → ToolCaller 经 "built-in" 服务调用该函数(context, **args)
  → 返回 ToolResult(data) 注入 Agent 上下文 → 决策下一步
```

> 前提：`builtin_tools.py` 在 runtime 进程内被导入（loader 引用它）；`variable_update`
> 还需容器注入（`agent_loader.load` 调用 `set_runtime_services(server.container)`）。

## 1. journey_node_counter —— 旅程节点访问计数器

- **含义**：按会话统计"进入某 tool 节点"的次数；典型用途：挽留次数计算（拒绝 N 次后转预约办理）。
- **实现**（`builtin_tools.py`）：`@p.tool` 函数，按 `(agent_id, session_id)` 内存字典计数 +1；
  `max_value` 可选，返回 `remaining` / `reached_limit`。
- **配置**：旅程 tool 节点 `tool_state: ["journey_node_counter"]`（可带 `{"max_value": 2}` 语义，但转移条件直接读 `count` 即可）。
- **局限**：按 `(agent_id, session_id)` 计数（同一会话内多个计数节点共享，节点维度需 ToolContext 带节点 id，当前未暴露）；单进程内存，重启清零；多进程/多 pod（阶段5）需换 Redis。

## 2. variable_update —— 声明式会话变量写入

- **含义**：把声明变量写进会话变量，驱动旅程分支。
- **实现**（`builtin_tools.py`）：`@p.tool` 函数，经注入的容器访问 `ContextVariableStore`；
  对 `variable_names` 中已声明的变量，取 `variable_selectors`（JSON 字符串，`{"varName":{"value":...}}`）
  里的 value，以 `key=customer_id` **客户级覆盖**写入（引擎按
  `customer.id > agent:<id> > 全局` 优先级读取，见 docs/03-production/09）。
- **配置**：tool 节点 `tool_state: ["variable_update"]`；指南 `tools: ["variable_update"]`；
  调用方（LLM）传 `variable_names` + `variable_selectors` JSON。
- **注**：@p.tool 仅支持 `list` 泛型注解，selectors 用 `str`（JSON 字符串）承载。
- **局限**：值必须由调用方在 selectors 里给出；变量未声明/无 value 则回执状态不写。

## 3. tavily_search —— 联网搜索

- **含义**：Tavily 联网搜索，返回 title/url/content 摘要。
- **实现**：`@p.tool`，POST `api.tavily.com/search`（`TAVILY_API_KEY`）；未配置/异常返回提示不抛错。
- **配置**：tool 节点 `tool_state: ["tavily_search"]` 或指南 `tools: ["tavily_search"]`。

## 4. 新增内置工具的步骤

1. `builtin_tools.py` 里加 `@p.tool async def xxx(context: p.ToolContext, ...) -> p.ToolResult`
   （首参必须 `context: p.ToolContext`，**不要用 `from __future__ import annotations`**——注解会变字符串导致装饰器断言失败）。
2. 加入 `BUILTIN_TOOLS` 字典 + `resolve_tool` 自动覆盖。
3. agent-definition.json tools[] 里声明同名工具（source="builtin"），供配置引用。

## 5. 与框架的关系

- **机制归框架**：`@p.tool` 装饰器、ToolEntry/ToolRef、集成 "built-in" 工具服务、ToolCaller 调用。
- **实现归我们**：三个工具的函数体、计数/写入语义、错误处理。
- 若 Parlant 后续原生提供同名工具，需评估优先级（外部 ToolService 注册 vs 内置声明）。
