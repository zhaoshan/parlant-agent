## 1. 统一信息架构（浅色平铺侧栏，不分组）

```
┌───────────────────────────────┐
│ (点击→首页) P AgentStudio·工作台 │
│ [当前 Agent ▾]  ← 下拉切换入口   │
├───────────────────────────────┤
│ ⚙ Agent 构建      （构建工作台） │
│ 💬 模拟对话        （预览窗口）  │
│ ↻ 自动仿真        （脚本+执行）  │
│ 📈 追踪与观测      （记录+链路）  │
│ ⚙ 设置                        │
└───────────────────────────────┘
```

- **首页入口 = 品牌**：左上角 AgentStudio / Agent 工作台 点击回 Agent 首页（onboarding，全宽无侧栏）。
- **切换 Agent = 下拉列表**：「当前 Agent」点击展开列表就地切换；"查看全部/创建"回首页。
- **浅色侧栏**：`#FFFFFF` + 发丝线，与工作区同色系。
- **Parlant 术语**：Agent 构建组件导航中中文名 + 括号英文术语（映射 Parlant 概念）。

## 3. 关键交互决策

1. **首页 = 品牌点击**；**切换 Agent = 侧栏下拉**（就地切换 + 查看全部/创建）。
2. **onboarding 无侧栏**：全宽卡片选择 → 进入 Agent 构建；卡片反映版本/加载/组件统计。
3. **发布即确认**：构建页"发布新版本"→ 弹窗（版本号 + 变更说明 + 发布影响提示）→ 确认发布；历史版本入口常驻。
4. **模拟对话 = 预览窗口**：工作台「试跑」→ 模拟对话新对话（选身份）→ 聊天窗；会话边栏/执行详情均可折叠。
5. **自动仿真 = 脚本驱动**：配置即"仿真脚本"（LLM 依背景/步骤/上一条回复生成提问）；可多次执行，执行记录独立查看。
6. **每轮可追溯**：会话记录按轮展开、每轮带 trace_id + langfuse 链接（依赖后端 `session_turns` 落库，见 plan 3.9）。
7. **会话记录分页**：追踪与观测翻页查询（每页 10）。
8. **Parlant 术语**：构建页组件导航中文名 + 括号英文术语（对齐 Parlant 概念，便于对照文档）。
